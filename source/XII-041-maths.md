# CBSE Class XII Mathematics (041): Pass Pack 2026-27

**Who this is for:** students who need to **pass**, meaning at least 33% in the theory paper (26 out of 80) and 33% in internal assessment (6 out of 20).
**How to use it:** Study the chapters in the order given in Section 3. Learn the starred (★) questions in Section 5 first. Then practise them by **writing** the full steps, not just reading them. In Maths, marks come from steps.

## 3. The 33-mark plan (target about 34 marks in theory, safely above 26)

### 3a. Study order (easiest and highest return first)

1. **Linear Programming (5 marks).** Same method every year: draw lines, shade, find corner points, put in Z. Almost a free 5.
2. **Matrices and Determinants (10 marks).** MCQs on order, transpose, |kA|, adj A; and the big one: find A⁻¹ and solve 3 equations. Asked every year we checked.
3. **Probability (8 marks).** Conditional probability MCQs and one Bayes' theorem / total probability question (often a case study). Same table method every time.
4. **Relations (5 marks) + ITF MCQs (3 marks).** The equivalence-relation proof is a fixed 3-step template (reflexive, symmetric, transitive).
5. **Vectors (about 5 marks).** Magnitude, unit vector, dot product, cross product, area of parallelogram. Short formulas.
6. **Differential Equations (5 marks).** Order/degree MCQ, integrating factor MCQ, one 3-mark DE (variable separable or linear).
7. **AOD (9 marks).** Rate of change (2-3 marks) and the case study on maximum value (first 2 parts are easy).
8. **Bonus if time:** C&D (chain rule, implicit, log, parametric), 3-D lines (direction ratios, shortest distance), easy integrals MCQs.

**Extra cushion (try, do not depend on):** C&D MCQs and one 2-3 mark differentiation (+3), 3-D direction ratios / angle between lines (+2), easy integral MCQs (+2).

### 3c. How internal assessment helps

- IA is **20 marks**, given by your school: 10 from periodic tests (best 2 of 3 averaged) and 10 from activities (record 5 + activity test 3 + viva 2).
- You need only **6 out of 20** in IA, but aim for 15+. Do all 10 lab-manual activities, keep a neat record file, and learn the viva questions for each activity. These are the easiest marks in the subject.
- Remember: IA is passed **separately**. Even 20/20 in IA will not save you if theory is below 26/80.

## 5. Must-do question bank (98 questions)

**Key:** ★ = learn first (repeated type). Year tags show the board paper where we saw this question or the same type ("SQP" = 2026-27 Sample Paper, "2026C" = 2026 compartment). "Practice" = NCERT-style question of a type that repeats; no year claimed.
For MCQs, the answer is given with a one-line reason. For long questions, write **every step** shown: each step carries marks.

### Chapter 1: Relations and Functions

**Q1. (MCQ, 2024)** A function f : R⁺ → R (R⁺ = non-negative reals) is defined by f(x) = 4x + 3. Then f is: (A) one-one but not onto (B) onto but not one-one (C) both (D) neither.
**Answer: (A).** f(x1) = f(x2) gives x1 = x2, so one-one. Range is [3, ∞), not all of R, so not onto.

**Q2. ★ (A-R, 2025)** Assertion (A): f : Z → Z, f(x) = 3x - 5 is a bijection. Reason (R): A function is a bijection if it is both one-one and onto.
**Answer: (D) A is false, R is true.** For y = 0, 3x - 5 = 0 gives x = 5/3, not an integer. So f is not onto, hence not a bijection.

**Q3. ★ (5 marks, 2018 type; also 2026)** Show that R = {(a, b) : a, b ∈ A, |a - b| is divisible by 4} on A = {x ∈ Z : 0 ≤ x ≤ 12} is an equivalence relation. Find the set of elements related to 1.
**Answer:**
- Reflexive: |a - a| = 0, and 0 is divisible by 4. So (a, a) ∈ R for all a ∈ A.
- Symmetric: if (a, b) ∈ R, then |a - b| = 4k. Now |b - a| = |a - b| = 4k, so (b, a) ∈ R.
- Transitive: if (a, b), (b, c) ∈ R, then a - b = ±4k and b - c = ±4m. Adding: a - c = 4(±k ± m), divisible by 4. So (a, c) ∈ R.
- Hence R is an equivalence relation.
- Elements related to 1: |1 - b| divisible by 4, so b = 1, 5, 9. The set is **{1, 5, 9}**.

**Q4. ★ (5 marks, 2026)** R = {(x, y) : |x - y| is divisible by a prime number p, x, y ∈ Z}. Check whether R is an equivalence relation.
**Answer:** Reflexive: |x - x| = 0 = p × 0. Symmetric: |y - x| = |x - y|. Transitive: x - y = pk and y - z = pm give x - z = p(k + m). **R is an equivalence relation.**

**Q5. (4 marks, 2020)** On N × N, (a, b) R (c, d) if and only if ad = bc. Show R is an equivalence relation.
**Answer:** Reflexive: ab = ba, so (a, b) R (a, b). Symmetric: ad = bc gives cb = da, so (c, d) R (a, b). Transitive: ad = bc and cf = de. Multiply: adcf = bcde. Cancel cd (non-zero, natural numbers): af = be, so (a, b) R (e, f). **Equivalence relation.**

**Q6. (Case study, 2025)** On A = {1, 2, 3}: R1 = {(2,3), (3,2)}, R2 = {(1,2), (1,3), (3,2)}, R3 = {(1,2), (2,1), (1,1)}, R4 = {(1,1), (1,2), (3,3), (2,2)}, R5 = {(1,1), (1,2), (3,3), (2,2), (2,1), (2,3), (3,2)}.
(i) Which is reflexive and transitive but not symmetric? (ii) Which is reflexive and symmetric but not transitive? (iii)(a) Which are symmetric but neither reflexive nor transitive? (iii)(b) What pairs must be added to R2 to make it an equivalence relation?
**Answer:** (i) **R4** ((1,2) is there but (2,1) is not). (ii) **R5** ((1,2), (2,3) are there but (1,3) is not). (iii)(a) **R1 and R3** (R1: (2,3), (3,2) but no (2,2); R3: (2,1), (1,2) but no (2,2)). (iii)(b) Add **(1,1), (2,2), (3,3), (2,1), (3,1), (2,3)**.

**Q7. (5 marks, SQP 2026-27 VI version)** R : (-∞, ∞) → [0, ∞), R = {(x, y) : y = x² + 7}. Is it a function? Is it one-one, onto, bijective?
**Answer:** Each x gives exactly one y = x² + 7, so it is a **function**. f(1) = f(-1) = 8, so **not one-one**. y = 0 (in co-domain) gives x² = -7, no real x; range is [7, ∞) ≠ [0, ∞), so **not onto**. Hence **not bijective**.

**Q8. (2 marks, 2019 type)** Show f : N → N, f(x) = x² + x + 1 is one-one but not onto.
**Answer:** If f(a) = f(b): a² + a = b² + b gives (a - b)(a + b + 1) = 0. Since a + b + 1 > 0, a = b: **one-one**. f(1) = 3 is the smallest value, so 1 and 2 have no pre-image: **not onto**.

### Chapter 2: Inverse Trigonometric Functions

**Q9. ★ (MCQ, SQP)** Domain of sec⁻¹(2x) is: (A) (-∞, ∞) (B) (-1/2, 1/2) (C) (-∞, -1/2) ∪ (1/2, ∞) (D) (-∞, -1/2] ∪ [1/2, ∞).
**Answer: (D).** sec⁻¹ needs |2x| ≥ 1, so |x| ≥ 1/2.

**Q10. ★ (2 marks, 2018)** Find tan⁻¹√3 - cot⁻¹(-√3).
**Answer:** tan⁻¹√3 = π/3. cot⁻¹(-√3) = π - cot⁻¹√3 = π - π/6 = 5π/6. Answer = π/3 - 5π/6 = **-π/2**.

**Q11. ★ (2 marks, 2025)** Evaluate tan⁻¹[2 sin(2 cos⁻¹(√3/2))].
**Answer:** cos⁻¹(√3/2) = π/6. So 2 cos⁻¹(√3/2) = π/3, sin(π/3) = √3/2, and 2 × √3/2 = √3. tan⁻¹√3 = **π/3**.

**Q12. (Case study parts, 2024)** (i) Find sin⁻¹(-1/2) - sin⁻¹(1). (ii) Find the domain and range of f(x) = 2 sin⁻¹(1 - x).
**Answer:** (i) -π/6 - π/2 = **-2π/3**. (ii) Need -1 ≤ 1 - x ≤ 1, so 0 ≤ x ≤ 2: **domain [0, 2]**. sin⁻¹ gives [-π/2, π/2], times 2: **range [-π, π]**.

**Q13. (MCQ, practice, type of 2020)** Principal value of tan⁻¹(tan 3π/4) is: (A) 3π/4 (B) -π/4 (C) π/4 (D) -3π/4.
**Answer: (B).** tan 3π/4 = -1 and tan⁻¹(-1) = -π/4 (must lie in (-π/2, π/2)).

**Q14. (MCQ, 2025)** The graph shown is y = cos x on [0, π] (decreasing from 1 to -1). Its inverse graph is the curve from (-1, π) to (1, 0).
**Answer:** The graph of **cos⁻¹x**: domain [-1, 1], range [0, π], decreasing, passes through (0, π/2). (In the 2025 paper this was option C.)

### Chapter 3: Matrices

**Q15. (MCQ, SQP)** A = [[2, 1, -2], [3a, 0, 4], [b, 2c, 1]] is symmetric. Then √(6a + 2b + 3c) is: (A) -2 (B) 2 (C) ±2 (D) 4.
**Answer: (B).** Symmetric means aᵢⱼ = aⱼᵢ: 3a = 1, b = -2, 2c = 4. So 6a + 2b + 3c = 2 - 4 + 6 = 4, √4 = 2.

**Q16. (MCQ, 2026)** If A and B are skew-symmetric matrices of the same order, which is also skew-symmetric? (A) AB (B) AB + BA (C) (A + B)² (D) A - B.
**Answer: (D).** (A - B)ᵀ = Aᵀ - Bᵀ = -A + B = -(A - B).

**Q17. (MCQ, SQP)** If [1 x] [[1, 0], [0, 2]] [[4], [-1]] = O, then x = ? (A) -2 (B) -1 (C) 1 (D) 2.
**Answer: (D).** [1 x][[1,0],[0,2]] = [1 2x]. Then [1 2x][4, -1]ᵀ = 4 - 2x = 0, x = 2.

**Q18. (MCQ, 2025)** A is 3×3, B is 3×1, C is 1×3. Which products are defined: AB, AC, BA?
**Answer: Only AB.** (3×3)(3×1) works. AC needs 3 = 1 (no). BA needs 1 = 3 (no).

**Q19. (3 marks, SQP)** P = [[2, 0, 0], [0, 1, 2]] and Q = [[1, 0], [0, 2], [1, 0]]. Find PQ and QP, and the inverse of the product if it exists.
**Answer:** PQ = [[2, 0], [2, 2]] (2×2). |PQ| = 4 ≠ 0, so (PQ)⁻¹ = (1/4)[[2, 0], [-2, 2]] = [[1/2, 0], [-1/2, 1/2]].
QP = [[2, 0, 0], [0, 2, 4], [2, 0, 0]] (3×3). Rows 1 and 3 are equal, so |QP| = 0: **inverse does not exist**.

**Q20. (3 marks, type of 2026C)** Express A = [[3, 5], [1, -1]] as the sum of a symmetric and a skew-symmetric matrix.
**Answer:** Aᵀ = [[3, 1], [5, -1]].
P = ½(A + Aᵀ) = ½[[6, 6], [6, -2]] = [[3, 3], [3, -1]] (symmetric, Pᵀ = P).
Q = ½(A - Aᵀ) = ½[[0, 4], [-4, 0]] = [[0, 2], [-2, 0]] (skew-symmetric, Qᵀ = -Q).
P + Q = [[3, 5], [1, -1]] = A.

### Chapter 4: Determinants

**Q21. ★ (MCQ, 2020)** A is a square matrix of order 3 and |A| = 5. Then |2A| = ?
**Answer: 40.** |kA| = kⁿ|A| = 2³ × 5.

**Q22. ★ (MCQ, 2025)** A is of order 2 and det A = 4. Then det(4 adj A) = ? (A) 16 (B) 64 (C) 256 (D) 512.
**Answer: (B).** |4 adj A| = 4² × |adj A| = 16 × |A|²⁻¹ = 16 × 4 = 64.

**Q23. (MCQ, 2023)** A is 3×3 and |adj A| = 64. Then |A| = ?
**Answer: ±8.** |adj A| = |A|² = 64.

**Q24. (MCQ, SQP)** P and Q are of the same order, P = [[2, 1], [0, 1]] and |Q| = 3. Find |adj(PQ)|.
**Answer: 6.** For 2×2, |adj M| = |M|. |PQ| = |P||Q| = 2 × 3 = 6.

**Q25. ★ (5 marks, practice: same type as 2016, 2018, 2019, 2020, 2023, 2024, 2026)** Using the inverse of a matrix, solve:
2x - 3y + 5z = 11, 3x + 2y - 4z = -5, x + y - 2z = -3.
**Answer:**
- Write AX = B: A = [[2, -3, 5], [3, 2, -4], [1, 1, -2]], X = [x, y, z]ᵀ, B = [11, -5, -3]ᵀ.
- |A| = 2(-4 + 4) + 3(-6 + 4) + 5(3 - 2) = 0 - 6 + 5 = **-1 ≠ 0**, so A⁻¹ exists (unique solution).
- Cofactors: A11 = 0, A12 = 2, A13 = 1; A21 = -1, A22 = -9, A23 = -5; A31 = 2, A32 = 23, A33 = 13.
- adj A = [[0, -1, 2], [2, -9, 23], [1, -5, 13]].
- A⁻¹ = adj A / |A| = -[[0, -1, 2], [2, -9, 23], [1, -5, 13]].
- X = A⁻¹B: x = -(0 + 5 - 6) = 1, y = -(22 + 45 - 69) = 2, z = -(11 + 25 - 39) = 3.
- **x = 1, y = 2, z = 3.**

**Q26. ★ (5 marks, 2025)** A school puts 180 students into Sports, Music and Drama clubs. Sports = Music + Drama. Music = (half of Sports) + 20. Find the numbers using the matrix method.
**Answer:**
- Let S, M, D be the numbers. Equations: S - M - D = 0; -S + 2M = 40 (from M = S/2 + 20); S + M + D = 180.
- A = [[1, -1, -1], [-1, 2, 0], [1, 1, 1]], B = [0, 40, 180]ᵀ.
- |A| = 1(2 - 0) + 1(-1 - 0) - 1(-1 - 2) = 2 - 1 + 3 = **4**.
- adj A = [[2, 0, 2], [1, 2, 1], [-3, -2, 1]].
- X = (1/4) adj A × B: S = (0 + 0 + 360)/4 = 90; M = (0 + 80 + 180)/4 = 65; D = (0 - 80 + 180)/4 = 25.
- **Sports 90, Music 65, Drama 25.**

**Q27. ★ (Case study 4 marks, SQP)** Basket A: 5 kg apples, 10 kg oranges, 5 kg pomegranates, cost ₹2750. Basket B: 10, 10, 5 kg, cost ₹3500. Basket C: 8, 15, 7 kg, cost ₹4100. (i) Write the matrix equation and find adj of the coefficient matrix. (ii) Find the price per kg of each fruit.
**Answer:**
- (i) Let x, y, z = price per kg of apple, orange, pomegranate. A = [[5, 10, 5], [10, 10, 5], [8, 15, 7]], X = [x, y, z]ᵀ, B = [2750, 3500, 4100]ᵀ, AX = B.
  adj A = [[-5, 5, 0], [-30, -5, 25], [70, 5, -50]].
- (ii) |A| = 5(70 - 75) - 10(70 - 40) + 5(150 - 80) = -25 - 300 + 350 = **25**.
  X = (1/25) adj A × B: x = (-13750 + 17500 + 0)/25 = 150; y = (-82500 - 17500 + 102500)/25 = 100; z = (192500 + 17500 - 205000)/25 = 200.
  **Apples ₹150/kg, oranges ₹100/kg, pomegranates ₹200/kg.**

### Chapter 5: Continuity and Differentiability

**Q28. ★ (A-R, 2025)** A: f(x) = 3x - 8 for x ≤ 5 and 2k for x > 5 is continuous at x = 5 for k = 5/2. R: f is continuous at a if LHL = RHL = f(a).
**Answer: (D).** f(5) = 15 - 8 = 7 and RHL = 2k. 2k = 7 gives k = 7/2, not 5/2. A is false, R is true.

**Q29. (2 marks, practice; type of 2023, 2026, 2026C)** Find k if f(x) = kx + 1 (x ≤ 5) and 3x - 5 (x > 5) is continuous at x = 5.
**Answer:** LHL = f(5) = 5k + 1. RHL = 15 - 5 = 10. 5k + 1 = 10 gives **k = 9/5**.

**Q30. (MCQ, 2025)** f(x) = |x| + |x - 1|. Then at x = 0 and x = 1, f is: (C) continuous but not differentiable.
**Answer: (C).** Modulus functions are continuous everywhere but have sharp corners where the inside is 0.

**Q31. (2 marks, 2024)** Is f(x) = x²|x| differentiable at x = 0?
**Answer:** f(x) = x³ for x ≥ 0 and -x³ for x < 0. LHD = lim (h→0) [-(-h)³ - 0]/(-h) = lim h³/(-h) = 0. RHD = lim h³/h = 0. LHD = RHD = 0, so **differentiable at x = 0**.

**Q32. ★ (3-5 marks, 2024 and 2025)** If √(1 - x²) + √(1 - y²) = a(x - y), prove dy/dx = √[(1 - y²)/(1 - x²)].
**Answer:**
- Put x = sin A, y = sin B. Then cos A + cos B = a(sin A - sin B).
- 2 cos((A+B)/2) cos((A-B)/2) = a × 2 cos((A+B)/2) sin((A-B)/2).
- Cancel: cot((A - B)/2) = a, so A - B = 2 cot⁻¹a (a constant).
- sin⁻¹x - sin⁻¹y = 2 cot⁻¹a. Differentiate: 1/√(1 - x²) - (1/√(1 - y²)) dy/dx = 0.
- **dy/dx = √(1 - y²)/√(1 - x²)**.

**Q33. (3 marks, 2024)** If y = (tan x)ˣ, find dy/dx.
**Answer:** log y = x log(tan x). Differentiate: (1/y) dy/dx = log(tan x) + x × (sec²x / tan x).
**dy/dx = (tan x)ˣ [log(tan x) + x sec²x / tan x]** (= (tan x)ˣ [log tan x + 2x / sin 2x]).

**Q34. (3 marks, SQP)** If x = sin³t, y = cos³t, find d²y/dx² at t = π/4.
**Answer:** dx/dt = 3 sin²t cos t, dy/dt = -3 cos²t sin t, so dy/dx = -cot t.
d²y/dx² = (d/dt of -cot t) × dt/dx = cosec²t / (3 sin²t cos t) = 1/(3 sin⁴t cos t).
At t = π/4: sin⁴t = 1/4, cos t = 1/√2: d²y/dx² = 1/(3 × 1/4 × 1/√2) = **4√2/3**.

**Q35. (3 marks, 2019)** If y = (sin⁻¹x)², prove (1 - x²) d²y/dx² - x dy/dx - 2 = 0.
**Answer:** y1 = 2 sin⁻¹x / √(1 - x²), so √(1 - x²) y1 = 2 sin⁻¹x. Square: (1 - x²) y1² = 4y. Differentiate: (1 - x²) 2y1y2 - 2x y1² = 4y1. Divide by 2y1: **(1 - x²) y2 - x y1 = 2**. Hence proved.

**Q36. (2 marks, 2025)** If tan⁻¹(x² + y²) = a², find dy/dx.
**Answer:** x² + y² = tan(a²), a constant. Differentiate: 2x + 2y dy/dx = 0, **dy/dx = -x/y**.

**Q37. (2 marks, SQP)** If y = sin(x + y), and dy/dx = 0, prove y = ±1.
**Answer:** dy/dx = cos(x + y)(1 + dy/dx), so dy/dx (1 - cos(x + y)) = cos(x + y). If dy/dx = 0, cos(x + y) = 0, so sin(x + y) = ±1, i.e. **y = ±1**.

**Q38. (MCQ, SQP)** Derivative of cos⁻¹(2x² - 1) with respect to cos⁻¹x is: **2**.
**Reason:** Put x = cos u: cos⁻¹(2cos²u - 1) = cos⁻¹(cos 2u) = 2u, and d(2u)/du = 2.

### Chapter 6: Applications of Derivatives (AOD)

**Q39. ★ (3 marks, SQP)** The circular area of vision on the ground of a surveillance drone increases at the rate of 44 m² per metre as it gains height. The radius of the circle increases at 6 m/s. Find the rate at which the height of the drone increases when the radius is 14 m. (Use π = 22/7.)
**Answer:**

- Given dA/dh = 44 m² per metre.
- dA/dt = (dA/dh) × (dh/dt), so 528 = 44 × dh/dt.
- **dh/dt = 12 m/s.**

**Q40. ★ (2 marks, 2026)** A room-freshener bottle is an inverted cone. The volume of perfume decreases at a steady 1 mm³/min. Find the rate at which the level of perfume is dropping when the level is 10 mm, if the semi-vertical angle of the cone is π/6.
**Answer:**

**Q41. (Case study 4 marks, 2023)** A conical tank (semi-vertical angle 45°) is full of water. Water drips out at a uniform rate of 2 cm³/s. (i) Find the volume in terms of radius r. (ii) Find the rate of change of radius when r = 2√2 cm. (iii) Find the rate at which the wet surface is decreasing when r = 2√2 cm.

**Q42. (2 marks, practice)** The side of an equilateral triangle increases at 3 cm/s. How fast is its area increasing when the side is 15 cm?

**Q43. (3 marks, practice, NCERT type)** Find the absolute maximum and minimum values of f(x) = 2x³ - 15x² + 36x + 1 on [1, 5].

**Q44. (4 marks, practice)** A farmer has 300 m of fencing. He wants to fence a rectangular field and also put one partition fence inside it, parallel to one side. Find the largest area he can enclose.

**Q45. ★ (Case study 4 marks, 2026)** A delivery company has 5000 subscribers paying ₹300 a year. For every ₹1 increase, 10 subscribers leave. The fee is increased by ₹x. (i) How many leave? (ii) Write revenue R(x). (iii) Find x for maximum R(x), and where R is increasing / decreasing.

**Q46. ★ (Case study 4 marks, SQP)** Water Quality Index W(x) = 35 + 1.6x - 0.02x², where x = investment in ₹ crore. (i) Find x at the stationary point. (ii) Find the maximum WQI using the second derivative test. (iii) Find W(35) and W(60) and compare with the maximum.

### Chapter 7: Integrals

**Q49. ★ (3 marks, 2026)** Evaluate ∫₀¹ x tan⁻¹x dx.
**Answer:** By parts (u = tan⁻¹x, v' = x):
- = [(x²/2) tan⁻¹x]₀¹ - ∫₀¹ (x²/2) × 1/(1 + x²) dx
- = π/8 - (1/2)∫₀¹ [1 - 1/(1 + x²)] dx = π/8 - (1/2)[x - tan⁻¹x]₀¹
- = π/8 - (1/2)(1 - π/4) = π/8 - 1/2 + π/8 = **π/4 - 1/2**.

**Q50. (3 marks, 2026)** Find ∫ x² / [(x² + 9)(x² + 16)] dx.
**Answer:**
- Put x² = t: t/[(t + 9)(t + 16)] = A/(t + 9) + B/(t + 16). A = -9/7, B = 16/7.
- Integral = -(9/7)∫dx/(x² + 9) + (16/7)∫dx/(x² + 16)
- = **-(3/7) tan⁻¹(x/3) + (4/7) tan⁻¹(x/4) + C**.

**Q51. (3 marks, practice, NCERT)** Find ∫ (x + sin x)/(1 + cos x) dx.
**Answer:** 1 + cos x = 2cos²(x/2) and sin x = 2 sin(x/2) cos(x/2).
- Integral = ∫ (x/2) sec²(x/2) dx + ∫ tan(x/2) dx.
- By parts, ∫(x/2) sec²(x/2) dx = x tan(x/2) - ∫ tan(x/2) dx.
- The two ∫tan(x/2) dx cancel: **x tan(x/2) + C**.

**Q52. (5 marks, SQP)** Evaluate ∫ from -a to a of √[(a - x)/(a + x)] dx.
**Answer:**
- Multiply top and bottom by √(a - x): integrand = (a - x)/√(a² - x²) = a/√(a² - x²) - x/√(a² - x²).
- The second part is an odd function, so its integral from -a to a is 0.
- First part: a × 2∫₀ᵃ dx/√(a² - x²) = 2a [sin⁻¹(x/a)]₀ᵃ = 2a × π/2.
- **Answer = πa.**

**Q53. ★ (3 marks, 2026)** If I₁ = ∫ from -π/4 to π/4 of dx/(1 + cos 2x) and I₂ = ∫ from -1/2 to 1/2 of |x| dx, show that I₁ - 4I₂ = 0.
**Answer:**
- 1 + cos 2x = 2cos²x, so I₁ = (1/2)∫sec²x dx = (1/2)[tan x] from -π/4 to π/4 = (1/2)(1 + 1) = **1**.
- |x| is even: I₂ = 2∫₀^(1/2) x dx = 2 × (1/8) = **1/4**.
- I₁ - 4I₂ = 1 - 1 = 0. Hence proved.

**Q54. (2 marks, SQP)** Evaluate ∫ dx / (x√(x⁶ - 1)).
**Answer:** Put x³ = t, 3x² dx = dt. Integral = ∫ x² dx/(x³√(x⁶ - 1)) = (1/3)∫ dt/(t√(t² - 1)) = **(1/3) sec⁻¹(x³) + C**.

**Q57. ★ (5 marks, 2026C; same type 2024)** Using integration, find the area bounded by the ellipse 9x² + 16y² = 144 and the lines x = 2 and x = -2.
**Answer:**

**Q58. ★ (5 marks, 2026C)** Using integration, find the area bounded by the curve y = x² and the line y = 2.

### Chapter 9: Differential Equations

**Q64. ★ (3 marks, SQP)** Find the particular solution of x dy + (y - x²eˣ) dx = 0, given y(1) = 0.
**Answer:**
- Divide by x dx: dy/dx + y/x = x eˣ. Linear, P = 1/x, Q = x eˣ.
- IF = e^(∫1/x dx) = x.
- Solution: xy = ∫x² eˣ dx = eˣ(x² - 2x + 2) + C.
- y(1) = 0: 0 = e(1 - 2 + 2) + C, so C = -e.
- **xy = eˣ(x² - 2x + 2) - e.**

**Q65. ★ (3 marks, 2024)** Find the particular solution of x² dy/dx - xy = x² cos²(y/2x), given y = π/2 when x = 1.
**Answer:**
- Divide by x²: dy/dx = y/x + cos²(y/2x). Homogeneous: put y = vx, dy/dx = v + x dv/dx.
- v + x dv/dx = v + cos²(v/2), so sec²(v/2) dv = dx/x.
- Integrate: 2 tan(v/2) = log|x| + C.
- x = 1, v = π/2: 2 tan(π/4) = 0 + C, so C = 2.
- **2 tan(y/2x) = log|x| + 2.**

**Q66. (3 marks, practice, NCERT)** Solve eˣ tan y dx + (2 - eˣ) sec²y dy = 0, given y = π/4 when x = 0.
**Answer:**
- Separate: sec²y/tan y dy = eˣ/(eˣ - 2) dx.
- Integrate: log|tan y| = log|eˣ - 2| + log|C|, so tan y = C(eˣ - 2).
- x = 0, y = π/4: 1 = C(1 - 2), C = -1.
- **tan y = 2 - eˣ.**

**Q67. ★ (3 marks, 2026)** Find the general solution of x² dy/dx = x² + xy + y².
**Answer:**
- dy/dx = 1 + y/x + (y/x)². Put y = vx: v + x dv/dx = 1 + v + v².
- x dv/dx = 1 + v², so dv/(1 + v²) = dx/x.
- tan⁻¹v = log|x| + C.
- **tan⁻¹(y/x) = log|x| + C.**

**Q68. (3 marks, 2026)** Find the particular solution of xy dy/dx = (x + 2)(y + 2), given y(1) = -1.
**Answer:**
- Separate: y/(y + 2) dy = (x + 2)/x dx, i.e. [1 - 2/(y + 2)] dy = [1 + 2/x] dx.
- Integrate: y - 2 log|y + 2| = x + 2 log|x| + C.
- x = 1, y = -1: -1 - 0 = 1 + 0 + C, so C = -2.
- **y - 2 log|y + 2| = x + 2 log|x| - 2.**

**Q69. (5 marks, 2026C)** Solve x² dy + y(x + y) dx = 0, given y = 1 when x = 1.
**Answer:**
- dy/dx = -(xy + y²)/x². Put y = vx: v + x dv/dx = -v - v², so x dv/dx = -(v² + 2v).
- dv/[v(v + 2)] = -dx/x. Partial fractions: (1/2)[1/v - 1/(v + 2)] dv = -dx/x.
- (1/2) log|v/(v + 2)| = -log|x| + log C, so v/(v + 2) = C²/x², i.e. y/(y + 2x) = K/x².
- x = 1, y = 1: 1/3 = K.
- **3x²y = y + 2x** (or y = 2x/(3x² - 1)).

**Answer:**
- Any point on the line: M(k, 2k + 1, 3k + 2). AM = (k - 1, 2k - 5, 3k - 1).
- AM ⊥ line: (k - 1) + 2(2k - 5) + 3(3k - 1) = 14k - 14 = 0, so k = 1.
- **Foot M = (1, 3, 5).**
- M is the mid-point of A and its image A'(x, y, z): (1 + x)/2 = 1, (6 + y)/2 = 3, (3 + z)/2 = 5.
- **Image A' = (1, 0, 7).** (In 2024 it was asked the other way: "the image of P is (1, 0, 7), find P". Same working.)

**Q81. (3 marks, practice, NCERT)** Find the distance between the parallel lines r = i + 2j - 4k + λ(2i + 3j + 6k) and r = 3i + 3j - 5k + μ(2i + 3j + 6k).
**Answer:**
- b = 2i + 3j + 6k, |b| = 7. a2 - a1 = 2i + j - k.
- b × (a2 - a1) = (3(-1) - 6(1))i - (2(-1) - 6(2))j + (2(1) - 3(2))k = -9i + 14j - 4k.
- |b × (a2 - a1)| = √(81 + 196 + 16) = √293.
- **Distance = √293/7 units.**

**Q82. (Case study 4 marks, SQP)** Laser beams: l1: r = (λ + 1)i + (3λ + 2)j + (3 - λ)k; l2: r = 2(μ + 1)i + (3μ - 1)j + (μ + 1)k; l3: r = (γ + 3)i + (3γ - 1)j + (1 - γ)k. (i) Show l1 and l2 are not parallel. (ii) Show l1 and l3 are parallel. (iii) Find the shortest distance between l1 and l2.
**Answer:**
- Rewrite: l1: a1 = (1, 2, 3), b1 = (1, 3, -1); l2: a2 = (2, -1, 1), b2 = (2, 3, 1); l3: a3 = (3, -1, 1), b3 = (1, 3, -1).
- (i) 1/2 ≠ 3/3, so b1 and b2 are not proportional: **not parallel**.
- (ii) b3 = b1, so **l1 ∥ l3**.
- (iii) b1 × b2 = (3 + 3)i - (1 + 2)j + (3 - 6)k = 6i - 3j - 3k, |b1 × b2| = √54 = 3√6. a2 - a1 = (1, -3, -2). Dot = 6 + 9 + 6 = 21.
  **SD = 21/(3√6) = 7/√6 units.** (OR part, l1 and l3: b1 × (a3 - a1) = -9i + 0j - 9k, SD = 9√2/√11 units.)

**Q83. (2 marks, SQP)** The line through (2, 6, 5) and (3, p, 7) is parallel to the line through (-4, 3, 4) and (-1, 0, q). Find q/p.
**Answer:** Direction ratios: (1, p - 6, 2) and (3, -3, q - 4). Parallel, so 1/3 = (p - 6)/(-3) = 2/(q - 4). Hence p - 6 = -1, **p = 5**; q - 4 = 6, **q = 10**. **q/p = 2.**

### Chapter 12: Linear Programming

**Method (write these steps every time):** (1) draw each line by its two intercepts; (2) shade using the test point (0, 0); (3) list corner points; (4) make a table of Z at each corner; (5) if the region is unbounded, check the open half-plane (Z > max or Z < min) before concluding.

**Q84. ★ (3 marks, SQP)** Maximise Z = 40x + 30y subject to x + y ≤ 6, 2x ≥ y, y ≥ 2.
**Answer:**
- Lines: x + y = 6, y = 2x, y = 2. The feasible region is the triangle bounded by them.
- Corners: y = 2 and y = 2x: (1, 2); y = 2 and x + y = 6: (4, 2); y = 2x and x + y = 6: (2, 4).
- Z(1, 2) = 100, Z(4, 2) = 220, Z(2, 4) = 200.
- **Maximum Z = 220 at (4, 2).**

**Q85. ★ (3 marks, 2026)** Minimise Z = 13x - 15y subject to x + y ≤ 7, 2x - 3y + 6 ≥ 0, x ≥ 0, y ≥ 0.
**Answer:**
- Lines: x + y = 7 through (7, 0), (0, 7); 2x - 3y + 6 = 0 through (-3, 0), (0, 2). (0, 0) satisfies both.
- Corners: (0, 0), (7, 0), (3, 4) [solving x + y = 7 and 2x - 3y = -6], (0, 2).
- Z: (0, 0) = 0; (7, 0) = 91; (3, 4) = 39 - 60 = -21; (0, 2) = -30.
- **Minimum Z = -30 at (0, 2).** (The maximum, 91 at (7, 0), is also often asked.)

**Q86. ★ (4 marks, 2020)** A furniture trader has ₹50,000 to invest and space for at most 35 items. A chair costs ₹1000, a table ₹2000. Profit: ₹150 per chair, ₹250 per table. Formulate as an LPP and maximise profit.
**Answer:**
- Let x chairs, y tables. Maximise Z = 150x + 250y.
- Constraints: 1000x + 2000y ≤ 50000, i.e. x + 2y ≤ 50; x + y ≤ 35; x ≥ 0, y ≥ 0.
- Corners: (0, 0), (35, 0), (20, 15) [solving x + 2y = 50, x + y = 35], (0, 25).
- Z: 0, 5250, 6750, 6250.
- **Maximum profit ₹6750 with 20 chairs and 15 tables.**

**Q87. (3 marks, 2024)** Maximise Z = 500x + 300y subject to x + 2y ≤ 12, 2x + y ≤ 12, 4x + 5y ≥ 20, x ≥ 0, y ≥ 0.
**Answer:**
- Corners: (5, 0), (6, 0), (4, 4) [solving x + 2y = 12 and 2x + y = 12], (0, 6), (0, 4).
- Z: 2500, 3000, **3200**, 1800, 1200.
- **Maximum Z = 3200 at (4, 4).**

**Q88. (MCQ, 2023)** Corner points of a feasible region are (2, 72), (15, 20), (40, 15). For Z = 18x + 9y: (a) max at (2, 72), min at (15, 20) (b) max at (15, 20), min at (40, 15) (c) max at (40, 15), min at (15, 20) (d) max at (40, 15), min at (2, 72).
**Answer: (c).** Z(2, 72) = 684, Z(15, 20) = 450, Z(40, 15) = 855.

### Chapter 13: Probability

**Method for Bayes' theorem (use a table):** list each cause E1, E2, E3 with P(Ei) and P(A | Ei); multiply; add for total probability P(A); then P(Ei | A) = [P(Ei) × P(A | Ei)] / P(A).

**Q89. ★ (3 marks, 2026)** Bag I has 3 red and 4 white balls; bag II has 8 red and 6 white. A die is thrown: if it shows a number less than 3, a ball is drawn from bag I, otherwise from bag II. Find the probability that the ball is red.
**Answer:**
- P(E1) = P(die < 3) = 2/6 = 1/3; P(E2) = 2/3.
- P(red | E1) = 3/7; P(red | E2) = 8/14 = 4/7.
- P(red) = (1/3)(3/7) + (2/3)(4/7) = 3/21 + 8/21 = **11/21**.

**Q90. ★ (5 marks, SQP)** Users of a fitness app: Alpha 45%, Beta 30%, Gamma 15%, Delta 10%. Chance of a false heart-rate alert: 0.01, 0.02, 0.05, 0.01. (i) Find P(false alert). (ii) If a false alert occurs, find the probability it came from Beta.
**Answer:**
- (i) P(F) = 0.45(0.01) + 0.30(0.02) + 0.15(0.05) + 0.10(0.01) = 0.0045 + 0.006 + 0.0075 + 0.001 = **0.019**.
- (ii) P(Beta | F) = 0.006/0.019 = **6/19**.

**Q91. ★ (Case study 4 marks, 2024)** Severe, moderate and light turbulence are equally likely. The chance of a late arrival is 55%, 37% and 17% respectively. (i) Find P(late). (ii) If late, find the probability it was due to moderate turbulence.
**Answer:**
- (i) P(L) = (1/3)(0.55 + 0.37 + 0.17) = 1.09/3 = **109/300**.
- (ii) P(moderate | L) = (1/3)(0.37) / (109/300) = (37/300)/(109/300) = **37/109**.

**Q92. ★ (Long answer, 2019)** Operators A, B, C produce 1%, 5%, 7% defective items and work 50%, 30%, 20% of the time. An item is found defective. Find the probability it was produced by A.
**Answer:**
- P(D) = 0.5(0.01) + 0.3(0.05) + 0.2(0.07) = 0.005 + 0.015 + 0.014 = 0.034.
- P(A | D) = 0.005/0.034 = **5/34**.

**Q93. (4 marks, 2020)** Bag I has 3 red, 5 black; bag II has 4 red, 3 black. One ball is moved from bag I to bag II, then a ball is drawn from bag II. It is black. Find the probability that the moved ball was black.
**Answer:**
- E1: red moved, P = 3/8 → bag II has 5R, 3B, P(black) = 3/8.
- E2: black moved, P = 5/8 → bag II has 4R, 4B, P(black) = 4/8.
- P(black) = (3/8)(3/8) + (5/8)(4/8) = 9/64 + 20/64 = 29/64.
- P(E2 | black) = (20/64)/(29/64) = **20/29**.

**Q94. (2 marks, 2022)** A pair of dice is thrown. The sum is even. Find the probability that at least one die shows 3.
**Answer:** Even-sum outcomes = 18. Of these, with a 3: (3,1), (3,3), (3,5), (1,3), (5,3) = 5. **P = 5/18.**

**Q95. (2 marks, 2022)** A and B solve a problem with probabilities 2/3 and 3/5, independently. Find the probability that the problem is solved.
**Answer:** P(not solved) = (1/3)(2/5) = 2/15. **P(solved) = 1 - 2/15 = 13/15.**

**Q96. (MCQ, SQP)** A and B are independent, P(A) = 1/6, P(B) = k. P(exactly one occurs) = 1/3. Find k. (A) 1/4 (B) 2/3 (C) 3/4 (D) 5/6.
**Answer: (A).** P(A)P(B') + P(A')P(B) = (1/6)(1 - k) + (5/6)k = 1/3 → 1/6 + 4k/6 = 2/6 → **k = 1/4**.

**Q97. (MCQ, SQP)** A die is thrown twice. Find the probability that at least one number is 4, given that the sum is a multiple of 5.
**Answer: 4/7.** Sum 5 or 10: (1,4), (2,3), (3,2), (4,1), (4,6), (5,5), (6,4) = 7 outcomes. With a 4: (1,4), (4,1), (4,6), (6,4) = 4.

**Q98. (MCQ, SQP)** The probability of rain on a day is 1/5, independent of other days. The probability of rain on three consecutive days is: **(D) 1/125** = (1/5)³.

## 6. Quick revision sheet

### Relations and functions
- **Reflexive:** (a, a) ∈ R for every a. **Symmetric:** (a, b) ∈ R ⇒ (b, a) ∈ R. **Transitive:** (a, b), (b, c) ∈ R ⇒ (a, c) ∈ R. All three = **equivalence relation**.
- **One-one:** f(x1) = f(x2) ⇒ x1 = x2. **Onto:** range = co-domain (solve y = f(x) for x and check x lies in the domain). Both = **bijective**.
- Number of relations on a set with n elements = 2^(n²).

### Inverse trigonometric functions (principal value branches)
| Function | Domain | Range (principal value) |
|---|---|---|
| sin⁻¹x | [-1, 1] | [-π/2, π/2] |
| cos⁻¹x | [-1, 1] | [0, π] |
| tan⁻¹x | R | (-π/2, π/2) |
| cot⁻¹x | R | (0, π) |
| sec⁻¹x | R - (-1, 1) | [0, π] - {π/2} |
| cosec⁻¹x | R - (-1, 1) | [-π/2, π/2] - {0} |
- sin⁻¹(-x) = -sin⁻¹x, tan⁻¹(-x) = -tan⁻¹x, cosec⁻¹(-x) = -cosec⁻¹x.
- cos⁻¹(-x) = π - cos⁻¹x, cot⁻¹(-x) = π - cot⁻¹x, sec⁻¹(-x) = π - sec⁻¹x.
- Learn the table of values: sin(π/6) = 1/2, cos(π/6) = √3/2, tan(π/3) = √3, tan(π/4) = 1.

### Matrices and determinants
- Symmetric: Aᵀ = A. Skew-symmetric: Aᵀ = -A (diagonal all 0). A = ½(A + Aᵀ) + ½(A - Aᵀ).
- (AB)ᵀ = BᵀAᵀ; (AB)⁻¹ = B⁻¹A⁻¹. AB is defined only if columns of A = rows of B.
- For order n: |kA| = kⁿ|A|; |adj A| = |A|ⁿ⁻¹; |A⁻¹| = 1/|A|; |Aᵀ| = |A|; |AB| = |A||B|.
- A⁻¹ = adj A / |A| (only if |A| ≠ 0). adj A = transpose of the cofactor matrix. Cofactor Aij = (-1)^(i+j) × minor.
- 2×2 shortcut: for [[a, b], [c, d]], adj = [[d, -b], [-c, a]].
- **System AX = B:** |A| ≠ 0 ⇒ unique solution X = A⁻¹B. |A| = 0 and (adj A)B ≠ O ⇒ no solution.

### Continuity and differentiability
- Continuous at a: LHL = RHL = f(a). Differentiable at a: LHD = RHD. Differentiable ⇒ continuous (not the reverse; |x| at 0).
- d/dx: xⁿ = nxⁿ⁻¹; sin x = cos x; cos x = -sin x; tan x = sec²x; sec x = sec x tan x; eˣ = eˣ; log x = 1/x; aˣ = aˣ log a.
- sin⁻¹x → 1/√(1 - x²); cos⁻¹x → -1/√(1 - x²); tan⁻¹x → 1/(1 + x²).
- Chain rule; product (uv)' = u'v + uv'; quotient (u/v)' = (u'v - uv')/v².
- Log differentiation for (f)^g: take log first. Parametric: dy/dx = (dy/dt)/(dx/dt); d²y/dx² = d/dt(dy/dx) ÷ dx/dt.

### Applications of derivatives
- Rate of change: dA/dt = (dA/dr)(dr/dt). Write "decreasing at" for a negative answer.
- Increasing: f'(x) > 0; decreasing: f'(x) < 0. Find f'(x) = 0, split the number line, test signs.
- Local max/min: f'(c) = 0, then f''(c) < 0 ⇒ max, f''(c) > 0 ⇒ min.
- Absolute max/min on [a, b]: compare f at critical points AND end points.
- Areas/volumes to remember: circle πr², sphere (4/3)πr³, cone (1/3)πr²h, cone curved surface πrl, cylinder πr²h, equilateral triangle (√3/4)a².

### Integrals (standard results, + C)
- ∫xⁿ dx = xⁿ⁺¹/(n + 1); ∫1/x dx = log|x|; ∫eˣ dx = eˣ; ∫sin x = -cos x; ∫cos x = sin x; ∫sec²x = tan x.
- ∫dx/(x² + a²) = (1/a) tan⁻¹(x/a); ∫dx/(x² - a²) = (1/2a) log|(x - a)/(x + a)|; ∫dx/(a² - x²) = (1/2a) log|(a + x)/(a - x)|.
- ∫dx/√(a² - x²) = sin⁻¹(x/a); ∫dx/√(x² ± a²) = log|x + √(x² ± a²)|.
- ∫√(a² - x²) dx = (x/2)√(a² - x²) + (a²/2) sin⁻¹(x/a).
- By parts: ∫uv dx = u∫v dx - ∫(u' ∫v dx) dx. Choose u by **ILATE** (Inverse trig, Log, Algebraic, Trig, Exponential).
- ∫eˣ[f(x) + f'(x)] dx = eˣ f(x).
- Definite: ∫ₐᵇ f(x) dx = ∫ₐᵇ f(a + b - x) dx; ∫₀ᵃ f(x) dx = ∫₀ᵃ f(a - x) dx; ∫ from -a to a = 2∫₀ᵃ f if f is even, = 0 if f is odd.

### Area
- Area between curve and x-axis = ∫ₐᵇ y dx; with y-axis = ∫ y-limits of x dy. Between two curves = ∫(upper - lower) dx.
- **Diagram to learn:** draw the curve, mark the points where the curves meet, and shade the region. A neat sketch earns a mark by itself.
- Circle x² + y² = a²: area πa². Ellipse x²/a² + y²/b² = 1: area πab. Parabola y² = 4ax opens right; x² = 4ay opens up.

### Differential equations
- **Order** = highest derivative. **Degree** = power of the highest derivative (only when the DE is a polynomial in derivatives).
- Variable separable: put all y terms with dy and all x terms with dx, then integrate.
- Homogeneous: put y = vx, dy/dx = v + x dv/dx.
- Linear: dy/dx + Py = Q ⇒ IF = e^(∫P dx), solution y × IF = ∫Q × IF dx + C. (For dx/dy + Px = Q, swap x and y.)
- General solution has arbitrary constants; particular solution has none (use the given condition).

### Vectors
- |a| = √(a1² + a2² + a3²); unit vector â = a/|a|. Vector of magnitude k along a = k × â.
- a·b = |a||b| cos θ = a1b1 + a2b2 + a3b3. Perpendicular ⇔ a·b = 0.
- a × b = determinant |i j k; a1 a2 a3; b1 b2 b3|; |a × b| = |a||b| sin θ. Parallel ⇔ a × b = 0.
- Area of parallelogram (sides a, b) = |a × b|; with diagonals d1, d2 = ½|d1 × d2|. Area of triangle = ½|a × b|.
- Projection of a on b = (a·b)/|b|. |a × b|² + (a·b)² = |a|²|b|².
- Direction cosines: l² + m² + n² = 1.

### 3-D geometry (lines only)
- Line through point a, parallel to b: r = a + λb. Cartesian: (x - x1)/a = (y - y1)/b = (z - z1)/c.
- Line through two points: direction ratios (x2 - x1, y2 - y1, z2 - z1).
- Angle between lines: cos θ = |b1·b2| / (|b1||b2|). Perpendicular: a1a2 + b1b2 + c1c2 = 0.
- Shortest distance formulas: see box in Chapter 11. SD = 0 means the lines intersect.
- Foot of perpendicular: take a general point of the line with parameter k, make (point - P)·b = 0, find k. Image = 2 × foot - P.

### Linear programming
- Corner point theorem: if a max or min exists, it occurs at a corner point. Bounded region: both max and min exist.
- Unbounded region: draw Z = (value found) as an open half-plane; if it has any common point with the region, there is no max (or min).

### Probability
- P(A | B) = P(A ∩ B)/P(B). Multiplication: P(A ∩ B) = P(A) P(B | A).
- Independent: P(A ∩ B) = P(A) P(B). Then A', B' etc. are also independent.
- P(at least one) = 1 - P(none). P(exactly one of A, B) = P(A)P(B') + P(A')P(B) (independent case).
- Total probability: P(A) = Σ P(Ei) P(A | Ei). Bayes: P(Ei | A) = P(Ei) P(A | Ei) / P(A).

## 7. Answer-writing tips and 30-day timetable

### How to grab step marks and partial marks
1. **Attempt every question.** There is no negative marking. In MCQs, eliminate options and always mark one.
2. **Write the formula first**, then put the values. The formula line alone often earns ½-1 mark in CBSE marking schemes.
3. **Matrix question:** even if you cannot finish, write |A| ≠ 0 ⇒ A⁻¹ exists, the cofactors and adj A. Each step is marked separately (|A| about 1 mark, adj A about 2 marks, solution about 2 marks).
4. **LPP:** write the objective function and constraints, draw the graph with a ruler, label the lines and shade, then make the corner-point table. Graph alone gets about half the marks.
5. **Bayes' theorem:** define the events E1, E2, E3 and A in words, write the probabilities, then use the formula. Defining events is worth marks.
6. **Equivalence relation:** write three headings (Reflexive / Symmetric / Transitive) and a conclusion line. Each heading is marked.
7. **Area questions:** draw the figure, find the meeting points, write the integral with limits. The setup is worth 2-3 of the 5 marks.
8. **DE:** say what type it is (variable separable / homogeneous / linear), write IF if linear, then solve. Add "+ C" and use the given condition for the particular solution.
9. **Case studies:** parts (i) and (ii) are usually very easy (1 mark each). Never leave a case study blank.
10. **Units and final answer:** box or underline the final answer, write units (cm²/s, sq units, ₹).
11. **Time plan (3 hours):** Section A 35 min, B 20 min, C 35 min, D 45 min, E 25 min, last 20 min checking. Do the easy sections first if you like, but number answers correctly.
12. **Use the 15-minute reading time** to tick the questions from your strong chapters (LPP, matrices, probability, relations).
